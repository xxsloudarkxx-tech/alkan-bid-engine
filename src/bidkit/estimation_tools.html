3 · Ejecutar una fase con tu API
Revisando configuración…
Usa BIDKIT_API_BASE, BIDKIT_API_KEY y BIDKIT_MODEL en PowerShell antes de iniciar el motor. No pegues la clave aquí. Al ejecutar, se envían al proveedor las entradas, fuentes y resultados de herramientas de esta fase.
